# Roadmap

M0: tooling, strict contracts, bilingual empty shell, deployment gate. M1: pure engine, scoring and edge cases verified by unit tests. M2–M7 are not automatically started: lobby/Realtime; submission/player; synchronized playback; playable voting/reveal; polish; release.

Phase 2: server-authoritative engine with filtered views; in-app YouTube Data API search; winner playlist export; independent spectator mode (distinct from MVP late joins); jokers/power-ups; legal imprint and privacy policy for public operation.
